## Shopmart – E‑commerce Web App

Shopmart is a modern e‑commerce web application where users can browse products, add them to a cart, and proceed to checkout. It is built with Next.js and TypeScript for a fast, SEO‑friendly shopping experience.

---

## Features

- **Product browsing**: List and view product details.
- **Shopping cart**: Add, remove, and update items in the cart.
- **Responsive UI**: Optimized for desktop, tablet, and mobile.
- **Modern stack**: Next.js App Router with TypeScript and React.
- **Scalable structure**: Organized file structure for easy feature expansion.

---

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **UI**: React, (Tailwind CSS or CSS Modules – adjust to your setup)
- **Package manager**: npm or yarn (update commands below if you use yarn/pnpm)

---

## Getting Started

### Prerequisites

- **Node.js** `>= 18` (recommended)
- **npm** `>= 9` (or yarn/pnpm if you prefer)

### Installation

git clone <YOUR_REPO_URL>.git
cd shopmart
npm install
